# Dream Bags

Dream Bags is a web-based bag shopping application built using Java Servlets and JSP.  
The project provides a simple e-commerce flow where users can browse bags, manage their cart, add delivery details, and place orders.

## Features

- User signup and login
- Browse available bags
- Search for bags
- Add bags to cart
- Update cart items
- Wishlist functionality
- Address management
- Multiple payment options
  - Cash on Delivery
  - UPI
  - Credit/Debit Card
- Order placement and confirmation
- Admin functionality for managing bags

## Tech Stack

- **Java**
- **Servlets**
- **JSP**
- **JDBC**
- **MySQL**
- **HTML / CSS / JavaScript**
- **Apache Tomcat**
- **Railway** for deployment
